Experimental Regexp Library

The optional regexp module wraps PCRE2. It is not present in a default build. Enable it with LJ_PCRE2=1 and provide any necessary include and link flags: 

make clean
make LJ_PCRE2=1 PCRE2_CFLAGS=-I/path/to/include PCRE2_LIBS=-lpcre2-8

local regexp = require("regexp")
local rx = assert(regexp.compile("^(?<kind>[a-z]+)-(\\d+)$", "i"))
local first, last, kind, id = rx:find("Send-42")
-- first == 1, last == 7, kind == "Send", id == "42"

Functions

FunctionDescription
compile(pattern [, flags])Compile a PCRE2 pattern, returning pattern or nil, message.
pattern:find(subject [, start])Return one-based start and inclusive end positions followed by capture strings. Return no values when there is no match.
escape(text)Quote text for literal use inside a PCRE2 pattern.

Flags are i (case-insensitive), m (multiline), s (dot matches newline), u (UTF-8 and Unicode properties), and x (extended mode). Compiled patterns are userdata and release their PCRE2 code when collected.
