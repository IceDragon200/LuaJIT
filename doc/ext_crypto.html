Experimental Crypto Library

The optional crypto module is backed by OpenSSL. It is not included in a default build. Enable it with LJ_OPENSSL=1, providing include and link flags when OpenSSL is outside the compiler's standard search paths: 

make clean
make LJ_OPENSSL=1 OPENSSL_CFLAGS=-I/path/to/include OPENSSL_LIBS='-L/path/to/lib -lcrypto'

local crypto = require("crypto")

local key = crypto.random_bytes(32)
local nonce = crypto.random_bytes(12)  -- never reuse with the same key
local ciphertext, tag = crypto.aead_encrypt("chacha20-poly1305", key, nonce,
                                            "hello", "version=1")
local plaintext = assert(crypto.aead_decrypt("chacha20-poly1305", key, nonce,
                                             ciphertext, "version=1", tag))

Functions

FunctionDescription
random_bytes(length)Return cryptographically strong random bytes from OpenSSL.
hash(name, data)Return a SHA-2 digest.
hmac(name, key, data)Return a SHA-2 HMAC.
hkdf(name, ikm, salt, info, length)Derive bytes using HKDF.
constant_time_equal(left, right)Compare equal-length byte strings without an early content exit.
aead_encrypt(algorithm, key, nonce, plaintext [, aad])Return ciphertext, tag.
aead_decrypt(algorithm, key, nonce, ciphertext, tag)Decrypt without associated data.
aead_decrypt(algorithm, key, nonce, ciphertext, aad, tag)Decrypt with associated data.

Hash names are sha256, sha384, and sha512. AEAD algorithms are aes-256-gcm and chacha20-poly1305. Both require a 32-byte key, a 12-byte nonce, and produce or accept a 16-byte authentication tag. Authentication failures return nil, "authentication failed"; other invalid arguments raise ordinary Lua argument errors.

Lua strings are immutable garbage-collected values and are not securely erased. This small API deliberately omits raw block ciphers, password hashing, key storage, and streaming interfaces. Use a unique nonce for every encryption under a given key.
