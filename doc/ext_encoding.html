LuaJIT

Experimental Encoding Library

This local experimental extension provides strict byte encoding helpers. It is preloaded by LuaJIT, but only made visible after require. 

local encoding = require("encoding")

local hex = encoding.hex_encode("\0\255")  -- "00ff"
local data = assert(encoding.hex_decode(hex))

local token = encoding.base64url_encode(data)  -- no trailing padding
local original = assert(encoding.base64url_decode(token))

Functions

FunctionDescription
hex_encode(data [, uppercase])Encode bytes as hexadecimal.
hex_decode(text)Decode hexadecimal bytes.
base64_encode(data)Encode RFC 4648 base64 with padding.
base64_decode(text)Decode strict, padded base64.
base64url_encode(data)Encode URL-safe base64 without padding.
base64url_decode(text)Decode URL-safe base64 with optional canonical padding.

The decoding functions return nil, message for malformed input. Wrong Lua argument types still raise the ordinary Lua argument error.
