LuaJIT

Experimental Pattern Matching

This is a local experimental language extension. It lowers patterns to normal LuaJIT calls, jumps, and assignments; it does not add VM bytecodes.

Table patterns

local {"ok", .name, count = n} = reply
local {header = {kind = "send", .flags}!} = packet

Bare names capture positional values. A leading dot captures a named key. Literal scalar values constrain a field or positional slot. A trailing ! requires a present, non-nil value. _ consumes a value without creating a binding. 

local {.kind, ...rest} = message

...rest captures a fresh, shallow table containing the direct fields not mentioned by this table pattern. It must be the final field. A nested rest captures at its own level; it does not flatten the parent table.

Binary patterns and construction

local bin{"P", kind <u8>, delta <integer(16, little, signed)>} = data

local frame = bin!{
  "P",
  kind <u8>,
  payload <bytes>
}

local bin{0xCA <u8>, 0xFE <u8>, version <u8>} = packet

Integer aliases are u8, u16, u24, u32, u40, u48, and their signed s* forms. Prefix an alias with le_ for little-endian order. Float aliases are f16, f32, and f64. The wordy forms accept little, big, native, signed, and unsigned. 

local bin{position <le_u16[3]>} = data
local data = bin!{position <le_u16[3]>}

Numeric vectors capture or construct a Lua array table. Fields remain byte-aligned; arbitrary bit-width fields are intentionally unsupported.

Numbers may be used as typed binary literals in a pattern. The literal is encoded with its declared integer or float decoder and then compared byte for byte, so a float literal has the decoder's exact on-wire precision.

Construction uses bin!{...}. The exclamation mark keeps ordinary Lua bin{...} calls available for the standard single-table-argument call syntax.

Case and pins

local result = case message do
when {kind = ^expected_kind, .payload} if payload ~= "" then payload
when bin{^magic, opcode <u8>} then opcode
else nil
end

The case subject is evaluated once. Clauses run in order and may use an if guard. A pin (^name) reads an already visible local, upvalue, or global and compares with raw Lua equality. Case may be used as a statement (with statement bodies) or as an expression (with one expression after each then).

Function parameters

local function handle({header = {kind = "send", .flags}!})
  return flags
end

local function decode(bin{"P", kind <u8>})
  return kind
end

Parameter patterns are strict: a non-matching call raises the same match error as a strict local pattern.

Strict-match diagnostics

Strict binary matches report the byte where matching stopped. Strict table matches report the key or positional slot that failed. case clauses continue to treat a mismatch as an ordinary failed clause.
