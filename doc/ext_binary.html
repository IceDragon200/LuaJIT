LuaJIT

Experimental Binary Library

This local experimental extension provides literal, byte-oriented operations on Lua strings. It is preloaded by LuaJIT, but is visible only after require. The API borrows its shape from Erlang's binary module while retaining Lua's string representation. 

local binary = require("binary")

local start, length = binary.match("GET /health HTTP/1.1", " ")
-- start == 3, length == 1; offsets are zero-based.

local words = binary.split("a,b,c", ",", { global = true })
local data = binary.replace("a.b", ".", "?", { global = true })

Every search is literal: characters such as ., *, and [ have no pattern meaning. Byte offsets and lengths are zero-based, which makes the returned offset, length pairs suitable for binary protocol work. Lua strings are immutable values, so part, split, and replace create Lua strings rather than Erlang sub-binary views.

Functions

FunctionDescription
at(data, offset)Return one byte (0–255). Raises for an out-of-range offset.
first(data), last(data)Return the first or last byte. Raise for an empty binary.
part(data, offset [, length])Return a strict byte slice. Without length, slice to the end.
compile_pattern(patterns)Copy one non-empty string or a sequence of non-empty strings into a reusable compiled pattern.
match(data, pattern [, options])Return offset, length for the first literal match, or no results.
matches(data, pattern [, options])Return a table of non-overlapping { offset, length } matches.
split(data, pattern [, options])Return fields split at literal matches.
replace(data, pattern, replacement [, options])Replace literal matches.
join(parts, separator)Join a sequence of byte strings.
longest_common_prefix(parts)Return the common prefix length in bytes.
longest_common_suffix(parts)Return the common suffix length in bytes.

Patterns and options

A pattern is one non-empty string, a sequence of non-empty strings, or a value returned by compile_pattern. With several patterns, the earliest match wins; ties use the first supplied pattern. matches advances past each match, so its results do not overlap.

For match and matches, { start = N, length = N } limits searching to a byte range. replace accepts the same scope and preserves bytes outside it. split and replace replace or split only the first occurrence by default; pass { global = true } for every occurrence. split additionally accepts trim = true to drop trailing empty fields or trim_all = true to drop all empty fields.

Hexadecimal and base64 encoding remain in the separate encoding module. Integer packing, unaligned bit syntax, and BEAM-style zero-copy accounting are intentionally outside this first byte-aligned API.
