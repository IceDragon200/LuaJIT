LuaJIT

Experimental Time Library

The local time extension provides high-resolution clocks without adding a scheduler or a sleep function. It is preloaded by LuaJIT and is made visible with require. 

local time = require("time")

local started = time.monotonic()
-- Run a frame, benchmark an operation, or advance an emulator.
local elapsed = time.monotonic() - started

Functions

FunctionDescription
monotonic()Return high-resolution elapsed seconds from a clock that does not move backwards when the system time is adjusted.
wall()Return fractional Unix epoch seconds for timestamps. The system clock may jump forwards or backwards.
cpu()Return process CPU seconds, equivalent in meaning to os.clock().

Use monotonic() for elapsed-time measurement, real-time emulation, and benchmarking. Use wall() only when an externally meaningful date or timestamp is needed. All results are Lua numbers in seconds; the API does not expose an ostensibly exact nanosecond integer because ordinary LuaJIT numbers are floating point.

The implementation uses mach_absolute_time on Apple platforms, clock_gettime(CLOCK_MONOTONIC) on POSIX platforms, and QueryPerformanceCounter on Windows. It intentionally offers no sleep or wait primitive.
