Experimental UTF-8 Library

The local utf8 module implements the Lua 5.3 UTF-8 library. Lua strings remain byte strings; this module provides explicit UTF-8 decoding, encoding, character iteration, and byte-offset conversion. 

local utf8 = require("utf8")
local text = utf8.char(0x1f980, 0x20, 0x4c, 0x75, 0x61)

assert(utf8.len(text) == 5)
for byte_position, codepoint in utf8.codes(text) do
  print(byte_position, codepoint)
end

Functions

FunctionDescription
char(...)Encode Unicode code points as one UTF-8 string.
codepoint(s [, i [, j]])Return the code points that start in byte range [i, j].
codes(s)Return a generic-for iterator yielding byte position and code point.
len(s [, i [, j]])Return the character count, or nil, byte_position for malformed UTF-8.
offset(s, n [, i])Convert a character offset to a one-based byte position.
charpatternA Lua pattern that matches one UTF-8 character-shaped byte sequence.

The behavior and positions follow Lua 5.3. Positions are byte positions, not grapheme positions: a visible character made from multiple code points still has multiple UTF-8 characters here.
